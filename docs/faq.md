# Frequently asked questions

## Is this a production ML platform?

No. It is an educational notebook collection.

## Are healthcare predictions authoritative?

No. They are demonstrations and must not be used as clinical or high-impact decisions without extensive validation and governance.

## How do I reproduce a notebook?

Create the documented virtual environment, start Jupyter from the repository root, and run the notebook from a clean kernel.
