## 🧭 Recommended reading

**New learner:** start with the root README, then read Notebook Catalogue and Installation.

**Working with a dataset:** read Datasets, Methodology, and Reproducibility before execution.

**Comparing models:** read Evaluation and check how each notebook splits data and preprocesses features.

**Healthcare notebook work:** read Responsible AI before interpreting model outputs.

**Contributor:** read Development and the root CONTRIBUTING policy.

## ⚠️ Accuracy boundary

The repository contains notebook files but does not contain the referenced CSV datasets or a pinned dependency manifest. These guides document current notebook assumptions and recommend reproducible practices; they do not claim that all experiments were recently re-executed.
