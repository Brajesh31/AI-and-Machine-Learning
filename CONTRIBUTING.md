# Contributing

This repository contains educational machine-learning notebooks. Keep changes reproducible and explain data, preprocessing, model, and evaluation changes.

Install the notebook's dependencies in an isolated environment, run affected notebooks from clean kernels, and record Python and package versions when results change. Do not commit private datasets, credentials, generated caches, or machine-specific paths.

Pull requests should describe the notebook changed, validation performed, metric impact, and dataset provenance or license considerations.
